# ChatGPT Year in Review 2025

A personalized, interactive "Spotify Wrapped" style experience for ChatGPT usage data. This project visualizes a year of conversations, growth, and side quests, turning raw usage patterns into a narrative about engineering, career development, and personal interests.

![Project Preview](https://via.placeholder.com/800x400?text=ChatGPT+Year+in+Review+Preview)

## 📖 About The Project

This application serves as a portfolio piece and a personal reflection tool. It breaks down 2025's ChatGPT interactions into distinct "sections" that tell a story:

- **Power-User Patterns**: Usage statistics, peak hours, and domain breakdown.
- **Builder & Researcher Mode**: Highlights of major projects (Sahana, SUDOKN, KG-ITP).
- **Skill Tree**: Visualization of technical growth (React, Python, Data Engineering).
- **Side Quests**: Personal interests like travel, Pokémon GO, and style.
- **2026 Quests**: Forward-looking goals and predictions.

## 🛠 Tech Stack

- **Framework**: [React](https://react.dev/) (Vite)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rajeshsawant98/chatgpt-year-in-review.git
   cd chatgpt-year-in-review
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

## 🎨 Features

- **Interactive Tour**: A guided walkthrough of the year's highlights.
- **Filtering System**: Filter cards by category (Usage, Builder, Career, etc.).
- **Responsive Design**: Fully responsive layout that looks great on desktop and mobile.
- **Dynamic Animations**: Smooth transitions and entry animations using Framer Motion.
